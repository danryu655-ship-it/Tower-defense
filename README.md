# Tower Terakhir

Game tower defense fantasi **Glowmoth: Luma Defense**. Pertahankan Luma Core dari gerombolan monster dengan 3 menara — Lampion Panah, Meriam Batu, dan Sihir Cahaya — yang bisa di-upgrade sampai level 3 dan memilih elemen Api atau Air.

## Main

- **Mode Endless** — tanpa akhir, map berganti tiap 20 wave, monster keluar dari kedua gerbang.
- **Mode Quest** — 5 chapter cerita *The Sundered Prism*: Luminous Hollow, Sunken Sluice, Crystal Caverns, Blazing Ruins, dan The Core Sanctuary.
- **7 map lukisan asli** — Hutan Bioluminesen, Kanal & Obsidian, Gua Kristal, Laguna Karang, Rawa Kuil Kuno, Lembah Lava, Celah Gletser.
- **38 monster & bos** dengan sprite lukisan asli, 9 tower (3 jenis x 3 level) + 3 skill ikon.
- **Musik latar** synth WebAudio: Epik Fantasi di menu, Semangat Perang saat bermain.
- **Wave otomatis** — kalau tombol Mulai Wave tidak ditekan selama 5 detik, wave berikutnya jalan sendiri.

## Cara main

Buka `index.html` di browser, atau mainkan lewat GitHub Pages (aktifkan di Settings → Pages, source branch `main`):

https://danryu655-ship-it.github.io/Tower-defense/

Seret tower dari dock ke alas batu kosong. Klik tower yang sudah dipasang untuk upgrade atau jual. Selesaikan wave untuk mendapat koin.
